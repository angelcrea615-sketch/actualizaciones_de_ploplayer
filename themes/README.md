# ProPlayer · Temas estacionales HTML

Cada tema es un documento HTML independiente. El cargador lee su CSS y sus elementos decorativos y los aplica a la interfaz principal; no inserta ni ejecuta scripts del tema.

Temas: Año nuevo, San Valentín, Primavera, Verano, Otoño, Halloween, Otoño tardío y Navidad.

En Ajustes > Apariencia puedes elegir Automático, Tema predeterminado o activar manualmente cualquiera de los temas. La elección manual se conserva al reiniciar. Actualizar temas descarga el manifiesto y los HTML desde GitHub.

Para publicar, conserva esta carpeta y sus rutas en `main/themes/`.
